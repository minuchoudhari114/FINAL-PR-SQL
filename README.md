## 🌟 Project Overview

The **University Course Management System** is a database project developed using **SQLite**.

It is designed to manage important university information such as:

- 👨‍🎓 Students
- 📖 Courses
- 🏢 Departments
- 👨‍🏫 Instructors
- 📝 Student Enrollments

The project demonstrates important **SQL database concepts**, including:

> Tables • CRUD Operations • Joins • Aggregate Functions • Subqueries • String Operations • Date Functions • CASE Statements
